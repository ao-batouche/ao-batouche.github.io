c The compression pipeline

Open a step to see what it changes.

1 Distillation teacher 7B

Train a small student model to copy a large teacher. The student learns from the teacher’s probability distribution, not only the correct answer. You pay for a training run and get a permanently smaller model.

2 Pruning 0% removed

Zeros were removed, but latency is unchanged. A dense kernel still multiplies by zero at full price—turn on step 6 to skip them.

Delete the weights that matter least—here, the smallest ones. Unstructured pruning leaves holes scattered through the matrix, so it needs a sparsity-aware runtime to become faster. Structured pruning removes whole channels or heads and is easier for ordinary kernels to exploit.

3 Healing raw

A short retraining pass lets surviving weights cover some of what the deleted weights were doing. It usually uses a small calibration set and far fewer steps than the original training run.

4 Fine-tuning general

Fine-tuning specializes a general model for one task. A small adapter can improve task fit without changing every base weight. It does not automatically make the base model smaller, but it can recover useful performance after compression.

5 Quantization FP32

Store each weight with fewer bits. Memory falls immediately, and supported hardware can move and multiply low-precision values faster. Very low precision introduces rounding error, so calibration matters.

6 Sparse runtime dense kernel

A runtime with kernels that understand the pruning pattern can skip zero weights. Without that software and hardware support, a sparse checkpoint may use less storage while running no faster.

d Three related techniques

Often discussed in the same conversation, but they solve different bottlenecks.

7 · Adaptation LoRA & adapters

Freeze the base model and train a small low-rank update. This makes task-specific training and storage cheaper, but the original base model still has to be loaded for inference.

8 · Training Quantization-aware training

Simulate low-precision rounding during training so the model learns weights that survive it. This can preserve more quality than quantizing a finished model, at the cost of additional training.

9 · Decoding Speculative decoding

Let a small draft model propose several tokens, then verify them with the large model in one pass. The large model is not compressed, but accepted drafts can reduce end-to-end generation time.
